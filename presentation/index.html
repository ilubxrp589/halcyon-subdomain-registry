The Problem

Traditional Domains (ICANN)

  • You rent, you never own
  • Can be seized by governments or registrars
  • Censorship at the root level
  • Yearly fees to middlemen (GoDaddy, Namecheap)
  • WHOIS exposes your personal info
  • No programmability or composability

HSR Domains (Handshake + Flare)

  • You OWN the DNS record on-chain
  • Nobody can seize or censor it
  • Decentralized root zone (Handshake)
  • One-time purchase, low renewal
  • Pseudonymous wallet-based ownership
  • NFT = tradeable, programmable asset

The Solution

HSR bridges Flare Network (smart contracts & payments) with Handshake (decentralized DNS) to create NFT-backed domains that resolve on the real internet.

DNS Pipeline

How a domain actually resolves

1

HNS Full Node (port 12037)

Synced to Handshake mainnet (~315k blocks). Stores TLD ownership records. We own the TLDs outright (cryptofans, aiworktools, cryptodnd, etc.)

2

NS Records on Handshake

TLD NS records point to our nameserver IP (174.163.11.200). This is written directly to the HNS blockchain via UPDATE transactions.

3

PowerDNS (port 53 + API 8081)

Serves authoritative DNS for each subdomain. Supports A, AAAA, CNAME, TXT, MX records. Auto-creates zones per TLD.

4

Resolution

HNS-aware resolvers (Unbound on .67, HDNS.io, NextDNS) query our PowerDNS. Regular DNS needs an HNS bridge. The domain resolves to real IPs.

Q&A Prep

"Why Flare and not Ethereum?"
Flare has FTSO — a native decentralized price oracle. No Chainlink dependency. Gas is ~$0.003 vs $5-50+ on Ethereum. It's EVM-compatible so same tooling (Hardhat, ethers.js, OpenZeppelin). Plus Flare's data connectivity layer enables cross-chain.
"Why Handshake instead of ENS?"
ENS only resolves inside crypto wallets. Handshake replaces the ICANN root zone — real DNS, real browsers. We own the TLDs outright. Subdomains get actual A records, MX records, everything. It's not just a naming service, it's actual infrastructure.
"Does DNS actually resolve in a normal browser?"
Yes, if you're using an HNS-aware resolver (NextDNS, HDNS.io, or our Unbound resolver at 192.0.2.67). Without that, you need a bridge. Same as how .onion needs Tor. The resolution is real — dig it in terminal and you get an A record back.
"What's the oracle pattern?"
Contract Listener watches Flare for SubdomainPurchased events. DNS Oracle takes that event, registers NS + GLUE records on Handshake via our full node, verifies propagation, then signals the contract to mint the NFT and release escrow. It's an off-chain oracle with on-chain verification.
"How do you prevent squatting?"
Character-based pricing (1-char = $500, 4+ = $10). Annual renewal required (365 days + 60 day grace). Expired domains go to auction. The economics naturally disincentivize hoarding.
"What about scaling?"
Flare handles thousands of TPS. PowerDNS handles millions of queries. GPU cluster scales horizontally — just add machines. DB is PostgreSQL with proper indexing. The bottleneck is HNS block time (~10 min) for propagation, but that's a one-time wait per domain.
"Why build your own marketplace?"
ERC-2981 royalties are enforced by our marketplace contract (2.5%). OpenSea doesn't enforce creator royalties anymore. Plus we have domain-specific features: auction with reserve, bundled DNS transfer, renewal management. Generic NFT marketplaces don't handle that.
"What's the revenue model?"
Domain registration fees (FLR), annual renewals, 2.5% marketplace transaction fees, and preview credit purchases for AI art generation. Multiple revenue streams, all on-chain.
