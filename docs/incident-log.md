# Incident Log

Track production issues, outages, and significant failures. Each incident gets a post-mortem so the same thing doesn't happen twice.

---

## Template

```
### INC-XXX: [Title]
**Date:** YYYY-MM-DD
**Severity:** Critical / High / Medium / Low
**Duration:** How long was the issue active
**Impact:** What was affected (registrations, DNS, NFTs, etc.)

**What happened:**
Brief description of the incident.

**Timeline:**
- HH:MM — Issue detected
- HH:MM — Investigation started
- HH:MM — Root cause identified
- HH:MM — Fix deployed
- HH:MM — Verified resolved

**Root cause:**
What actually went wrong.

**Fix applied:**
What was done to resolve it.

**Prevention:**
What changes were made to prevent recurrence.

**Action items:**
- [ ] Item 1
- [ ] Item 2
```
